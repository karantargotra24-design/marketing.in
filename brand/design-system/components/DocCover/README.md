# DocCover

The A4 cover for proposals, audits and onboarding PDFs: black (default) or white, wordmark top-left, serif title with one red caps word, red rule, footer meta line.

- Shown here at 297 × 420 (a quarter of A4 at 72dpi); scale up for print.
- Meta line: document type and date on the left, scapemedia.in on the right. Never a client name on a public sample.
