01Caption first drafts

TOOLChatGPT (or any AI chat)

02Summarise long documents

TOOLClaude (or any AI chat)
Here are my notes / client brief: [paste text] Summarise in a table with 3 columns: Key decisions | Open questions | Next steps (owner + deadline if mentioned). Don't add anything that isn't in the text. Flag anything unclear.

03Research a topic fast

TOOLGemini (or any AI chat with web access)

TOOLAny AI chat
