# SOP: Fact status labels
VERIFIED — checked against the primary source by a human or an official record, dated.
CLIENT-PROVIDED — the client or Karan supplied it; not independently checked.
RESEARCHED — found in a cited public source (URL + date).
INFERRED — reasoned from other facts; say from what.
ASSUMPTION — a working guess to be tested.
NEEDS VERIFICATION — conflicting, stale, unknown or placeholder. Never use in public marketing.
Updating a fact creates a new version; the old one stays as history.
