# Style blueprint (reel format)
**Observed** = seen in refs. **Rec** = my adaptation for ScapeMedia.

| Area | Spec |
|---|---|
| Format | Observed 9:16 (720x1280). Rec: render 1080x1920, 30fps, H.264 CRF18 + AAC 192k |
| Structure | A-roll → cutaway every 3–5s → back to A-roll; hook in first 1s; CTA last 3s |
| Captions | One word at a time, pop-in (4 frames, overshoot), upper third (y≈30%), Inter Display SemiBold 104px (Rec; refs look Helvetica-like — substitution) |
| Emphasis | Red (#FF2828) + glow, uppercase, 116px; tag 1 word per sentence max |
| Cutaway cards | Off-white #FAFAFA, black Inter Display Bold, title + coloured rounded tiles (#4FA8FF #FF8FB8 #9BE37A #FFD84D), staggered pop, hard cut out |
| Transitions | Hard cuts on word boundaries (Observed); no fades |
| Colour | Leave footage natural (Observed). Rec: light contrast lift only |
| Audio | Voice highpass 70Hz, whoosh at card in/out, tick on emphasis, loudnorm -14 LUFS / -1 dBTP |
| CTA | "Comment 'KEYWORD'" pill + topic line (Observed in B) — Rec for ScapeMedia: keyword → DM automation |
