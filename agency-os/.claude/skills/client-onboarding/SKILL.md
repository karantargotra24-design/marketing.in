# client-onboarding

**Purpose:** Create a complete workspace profile for a new client.

**Required inputs:** business name, services, audience, goals, accounts, competitors, brand assets

**Workflow:** 1 Create clients/<id>/ from template. 2 Ask only for missing essentials (one batch). 3 Fill profile, brand-guidelines, audience-personas. 4 Add to registry. 5 Log in audit-trail.

**Output template:** client-profile.md + registry row

**Quality checklist:** Unique ID; unknowns marked _unknown_; confidentiality noted. Plus rules in knowledge/00 (sources, no invented data, isolation).

**Example invocation:** /onboard-client Acme Dental
