# website-conversion-audit

**Purpose:** Review a website for conversion and clarity.

**Required inputs:** URL

**Workflow:** 1 Fetch page. 2 Check offer clarity, CTA, speed hints, trust, mobile, tracking. 3 List fixes ranked.

**Output template:** audits/website-<date>.md

**Quality checklist:** Observed vs inferred separated. Plus rules in knowledge/00 (sources, no invented data, isolation).

**Example invocation:** /audit client-001 website
