# Button

Three buttons: primary (red fill) for the one main action, secondary (outline) for the alternative, and link (red text with arrow) inside cards.

- One primary button per section. Labels in sentence case, verb first: *Get a free growth audit*, *See our work*.
- Height 48px, radius-sm, Plus Jakarta Sans 700 15px. Hover darkens to red-deep.
- On the red CTA band use the white-on-red variants (see CTABand).
- Consumer provides: the label and the href.
