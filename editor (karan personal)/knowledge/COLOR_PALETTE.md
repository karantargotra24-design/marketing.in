# Colour Palette

## 1. Karan's personal brand — VERIFIED (Design System v2, Oct 2026)
Source: Karan's design-system artifact (README + Canva Brand Kit list in checklist.md).

| Role | Token | Hex | Use |
|---|---|---|---|
| **Signature accent** | brand-red | **#FF0000** | Key word, numbers, arrows, CTA only. ONE red thing per design. Never backgrounds, never body text. 24px+ only on light grounds. |
| Ground | white | #FFFFFF | Type covers, inside slides |
| Ink | ink | #111111 (Brand Kit) / #000000 (tokens) | Text on white/sand |
| Warm ground | sand | #EDE5D8 | Alternate slides, Stories, quote cards |
| Photo ground | espresso | #2A211B | Dark covers, shadow grade target |
| Text on photo | cream | #F5EFE3 | Headlines over photos/espresso, CTA pill on photos |
| Muted on dark | stone | #C9B8A3 | Sub-lines, handle on photos |
| Warm detail | clay | #7A5A40 | Small labels, kickers, source lines |
| Photo overlay | scrim | rgba(26,20,16,.55) | Gradient behind text on photos only |
| Hairline | gray-200 | #E5E5E5 | Dividers on white |

**Hard rules:** warm, never blue (no blue/teal/purple casts, no blue shirts, no blue logos as hero). No emoji in designs. Max one ✳ (cream or clay).

### Known token bugs in the artifact (not yet fixed by Karan — do NOT copy these values)
- gray-500 = #F3F3F3 → muted text invisible on white. Use **#666666**.
- gray-300 = #000000 → invisible on black. Use **#A3A3A3**.
- gray-800 = #FFFFFF → bright hairlines on black. Use **#333333**.
- red-600 = #FF0000 → small white button labels fail contrast. Use **#DC2626** for button fills.
- dark-gray = #000000 (comment says slate) — treat as black.
