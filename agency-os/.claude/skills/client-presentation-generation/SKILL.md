# client-presentation-generation

**Purpose:** Monthly client deck/report draft.

**Required inputs:** month's reports, wins, next plan

**Workflow:** 1 Pull only this workspace's files. 2 Outline. 3 Draft slides (Gamma/Canva only after approval).

**Output template:** reports/deck-<month>.md

**Quality checklist:** No cross-client data. Plus rules in knowledge/00 (sources, no invented data, isolation).

**Example invocation:** /present-month client-001
