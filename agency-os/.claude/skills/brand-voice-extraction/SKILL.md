# brand-voice-extraction

**Purpose:** Derive voice rules from existing content.

**Required inputs:** 3-10 sample posts or site copy

**Workflow:** 1 Read samples. 2 Extract tone, vocabulary, do/don't, sentence length. 3 Write rules with examples.

**Output template:** brand-guidelines.md voice section

**Quality checklist:** Rules traceable to samples. Plus rules in knowledge/00 (sources, no invented data, isolation).

**Example invocation:** used by copywriter
