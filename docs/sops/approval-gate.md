# SOP: Approval gate
Needs Karan's explicit approval, every time: publishing/scheduling a post, launching or changing an ad, any spend, any message to a client or lead, any change to a production system.
Agents may research, analyse, draft and plan. They record an approval request; only a human decision unlocks it, and even then the action runs only through an integration that is connected AND tested. Today none is, so nothing external can execute.
