# editor (karan personal)

Karan's long-term personal editing workspace (ScapeMedia).

## How to use
Open Claude Code and say e.g. *"Use editor (karan personal) — edit this reel in Style B, keyword PRICE."*
Claude reads `CLAUDE.md` here (auto-loaded when working inside this folder) → knowledge files → follows the 7-step workflow.

## Structure
- `CLAUDE.md` — persistent instructions
- `knowledge/` — style rules (master guidelines, visual, typography, colour, content, reference analysis)
- `references/` — reference material (videos stored as contact sheets; raw media git-ignored)
- `projects/<client-or-topic>/` — working files + versioned outputs
- `templates/` — reel brief + QC checklist
- `changelog/STYLE_UPDATES.md` — every approved style change

## To teach a new preference
Say: *"Save this to my style"* → Claude updates the knowledge file and logs it.
